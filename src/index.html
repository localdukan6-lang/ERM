Workflow

  1. Choose Purchase or Sales.
  2. Select a party if applicable.
  3. Scan barcode, enter quantity, and add each variant.
  4. Review amounts and paid amount.
  5. Post. Stock and transaction history update atomically.

This starter currently uses product GST rates for reference only; tax-inclusive/exclusive GST invoice calculation is not yet implemented.
